# LESSONS
2026-10-17｜即將扣款跨月時以月初為基準計算，次月 1 號被標已扣款｜重用 StatsCalc 產生跨月清單時必須以「所選日」判定 debited，並為每個月份邊界（1 號、月底）寫測試
2026-10-17｜窄螢幕極大金額單行無省略/縮放而被截斷｜金額 Text 一律設 autoSize 或 overflow，並以 NT$99,999,999 在 360dp 預覽驗證
2026-10-17｜客戶卡每月合計未套用開始日期規則，與統計口徑不一致｜同一金額概念只用一個計算函式，UI 不自行加總
2026-10-17｜刪除客戶確認未說明會連帶刪除訂閱｜破壞性連帶刪除的確認框需列出受影響筆數
2026-10-17｜Release APK 無法由 tag commit 位元重現｜Release APK 由乾淨 checkout 建置並在說明附 commit 與 sha256
2026-10-17｜ShrinkText 只縮不長，寬度變大後字級不回復｜自適應字級的狀態必須以可用寬度為 key，並測旋轉/摺疊情境
