# 安麗長客統計 PWA — MVP 規格（v0.1.0）

iPhone 友善的離線網頁 App（zh-TW），功能對齊 Android 版 v0.2.1。記錄長期訂購客戶與每月扣款，統計當月已扣／待扣金額。

## 平台
- TypeScript + React + Vite；資料存在瀏覽器 IndexedDB（Dexie，DB 名稱 `amway-tracker`，schema v1）。
- Service Worker（vite-plugin-pwa / Workbox generateSW）預先快取全部檔案，離線可用；`registerType: autoUpdate`。
- Web App Manifest：`display: standalone`、`lang: zh-TW`、scope/start_url `/amway-tracker-pwa/`、192/512/maskable 圖示。
- iOS：`apple-touch-icon`（180px）、`apple-mobile-web-app-capable`、`apple-mobile-web-app-title`、`viewport-fit=cover`，以 `env(safe-area-inset-*)` 處理瀏海／Home 指示條；輸入欄位字級 ≥16px 避免 Safari 自動放大；底部表單隨 visualViewport 避開鍵盤。
- 深色模式跟隨系統（`prefers-color-scheme`），色票取自 Android 版 Theme.kt。
- **無網路呼叫**：除了載入 App 本身沒有任何請求；正式版 CSP `connect-src 'self'`；無分析、無外部字型／CDN。

## 資料
- **客戶**：姓名（必填）、電話、備註。刪除客戶會一併刪除其訂閱；確認框列出將刪除的訂閱筆數；月結快照保留。
- **產品**：名稱、單價（整數元）、最愛。仍有訂閱使用的產品不可刪除（UI 不顯示刪除，資料層交易內再檢查一次）。
- **訂閱**：客戶、產品（可搜尋的選擇器）、數量（−/＋ 步進器，1–999，也可直接輸入）、每月扣款日（1–31）、開始日期（原生日期選擇器）、狀態（進行中/暫停/結束）、備註。
  單價一律取自產品，不可覆寫；金額 = 產品單價 × 數量。
- **月結快照**：每個已結束月份每筆扣款的固定記錄（客戶、產品、單價、數量、金額、扣款日期）；另以 `snapshotMonths` 標記已快照的月份（含零筆）。
- 日期一律以 `YYYY-MM-DD` 字串儲存與計算（不受時區影響）；「今天」採裝置本地時間。

## 統計規則（單一計算來源 `src/domain/stats.ts` 的 `compute`）
- 選擇日期 D（預設今天），統計 D 所在月份。
- 只計入 狀態=進行中 且 開始日期 ≤ 當月扣款日期 的訂閱。
- 扣款日超過當月天數 → 當月最後一天（2/28、2/29、4/30）。
- 已扣款 = 扣款日 1 日～D（含）；剩餘 = D 之後至月底；本月總額 = 兩者和。
- 客戶卡／客戶詳情的本月合計 = `customerMonthTotal`，內部直接呼叫 `compute`（UI 不自行加總）。
- 即將扣款：D 之後 7 天內（不含 D、含 D+7，可跨月、跨年），**一律為「待扣款」**——debited 以所選日判定，而非跨月計算時使用的月初基準。
- 當月與未來月份即時計算；過去月份只讀月結快照（標示「月結快照（唯讀）」或「無快照資料」），不顯示即將扣款，永不重算。
- 快照產生：每次開啟 App（以及 App 從背景回到前景時），自最早訂閱開始月起，為所有已結束且尚未快照的月份以當下資料產生快照；在單一 IndexedDB 交易內重新讀取已快照月份，重複觸發不會產生重複資料。
- 明細可依客戶（名稱排序）或依扣款日分組，顯示小計與已扣小計。

## 預設產品
- `src/domain/products_seed.csv`：與 Android 版相同的 70 項單份產品（seed v1 58 項、v2 12 項）；`data/products_v2_raw.csv` 為原始來源，僅供測試比對。
- 版本化一次性匯入：IndexedDB `meta.seed_products_version` 記錄已套用版本；只匯入版本大於已套用版本的項目；名稱以 NFKC 正規化比對，同名略過、絕不覆寫；刪除過的預設產品不會再出現。
- 新安裝：匯入全部 70 項。

## 排序與搜尋
- 產品分頁與選擇器：最愛 → 常用（訂閱筆數 > 0，多者在前）→ 其他；同組依名稱。
- 搜尋為子字串比對，不分大小寫與全/半形（NFKC）；產品分頁有 全部/最愛 篩選。

## 匯出、備份與還原
- 訂閱 CSV、統計 CSV：UTF-8 含 BOM、逗號／引號／換行正確跳脫、CRLF 換行；欄位與 Android 版相同。
- 分享：有 `navigator.share` 且 `canShare({files})` 時以系統分享選單分享檔案（iPhone：可存到「檔案」、AirDrop、LINE…）；否則下載檔案。檔案內容於點擊當下同步產生，以保留 iOS 要求的使用者手勢。
- 完整備份：JSON（format `amway-tracker-backup`，version 1），含客戶、產品、訂閱、月結快照、快照月份、預設產品版本。
- 還原：嚴格驗證（關聯、數量、扣款日、日期、狀態）；確認框顯示各類筆數；在單一交易內取代全部資料（失敗則不變更）。
- 啟動時呼叫 `navigator.storage.persist()`；資料與備份頁顯示持久儲存狀態。

## UI
- 底部分頁：統計（首頁）、訂閱、客戶、產品，皆有圖示；右上「⋮」開啟資料與備份。
- 統計首頁：日期選擇＋「今天」、資料來源標示、三張大卡（本月總額、已扣款 1–D 日、剩餘）、即將扣款（未來 7 天）、本月明細。
- 訂閱卡：客戶、產品 × 數量、每月 N 號、金額、狀態色塊（進行中綠、暫停灰、結束淡化）。客戶卡：本月合計＋訂閱筆數（進行中數）。
- 「＋」浮動按鈕新增；表單為底部表單（bottom sheet）。
- 金額一律 `NT$1,234`（自行分位，不依系統語系），粗體；金額以縮放方式自動縮小以完整顯示（不截斷），可用寬度變大時恢復（以可用寬度重新計算）。
- 空狀態：說明＋「新增第一筆」；沒有客戶時新增訂閱會先開新增客戶，沒有產品時先開新增產品。

## 已知限制
- 資料只在單一瀏覽器／主畫面 App 內；iOS 上 Safari 分頁與主畫面 App 的儲存空間分開。需手動匯出備份，沒有雲端同步。
- 不提供從 Android 版匯入（Android 版沒有備份匯出）；CSV 僅供匯出檢視，還原使用 JSON 備份。
- 快照於開 App／回到前景時補產生，使用當下的產品單價與訂閱狀態（與 Android 相同）。
- 預設產品價格為抓取當時的公開網站價格，可能與會員價或現價不同。
- 快照建立後不可編輯；無結束日期欄位；金額以整數（元）計。
