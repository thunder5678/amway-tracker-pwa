# 驗收清單 AC_CHECKLIST — 安麗長客統計 PWA（v0.1.0）

> **DRAFT — 待核准。** 由 Android 版 AC 草案改寫為 PWA；核准前不得作為正式驗收依據，分級（必擋／警告）亦為草案。
> 驗證方式：U = 單元測試（Vitest）、E = 自動煙霧測試（`npm run smoke`，Playwright Chromium + iPhone 13 視窗）、S = 靜態檢查、R = iPhone 實機（Safari／主畫面）。
